# E-Commerce Sales Analysis

An end-to-end e-commerce sales analysis project using **MySQL, SQL, Power BI, and DAX**.  
The project analyzes sales performance, customer behavior, product performance, order operations, and payment trends to derive meaningful business insights.

## Project Overview

This project uses an e-commerce dataset containing customer, product, category, order, order detail, and payment information.
The analysis was performed in two stages:
- **SQL:** Data exploration, aggregation, customer analysis, product analysis, and business insight generation.
- **Power BI:** Interactive dashboard development using DAX measures and visualizations.

## Tools & Technologies
- **MySQL** – Database management and SQL analysis
- **SQL** – Data analysis and business queries
- **Power BI** – Interactive dashboard and data visualization
- **DAX** – Measures and calculated metrics

## Dataset
The database consists of six related tables:

- `customers` – Customer information
- `categories` – Product category information
- `products` – Product details
- `orders` – Order information and order status
- `order_details` – Products, quantities, prices, and discounts for each order
- `payments` – Payment methods and payment information
